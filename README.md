# Roblox Cameraman Tower Defense

This project is a Roblox script that implements a camera movement system and unit cloning functionality for a tower defense game. The camera movement system ensures the camera follows the player character, providing a smooth and immersive gameplay experience. The unit cloning functionality allows for the creation of multiple units, enhancing the strategic depth of the game.

## Install

1. Open Roblox Studio and create a new place or open an existing one.
2. Insert the `CameraMovementScript.server.lua` into the `ServerScriptService` folder.
3. Insert the `unit_clone.lua` script into the desired location within your game hierarchy.

## Use

1. Play the game to see the camera follow the player character.
2. To clone a unit, use the `cloneUnit` function in the `unit_clone.lua` script. Pass the original unit as an argument to create a clone.
